# 网易云服务集成

服务固定为 `@neteasecloudmusicapienhanced/api@4.41.1`，Node 固定为 `22.22.0`。
`package.json` 和 `package-lock.json` 提交到仓库，生产依赖与目标平台运行时由
`scripts/prepare_netease.py` 准备到 `src/autoskyplay/assets/netease/`。
生成目录被 Git 忽略，源码首次运行前需执行准备脚本；`scripts/build.py` 和 CI 自动执行该步骤。
PyInstaller 将整个服务资源树和 Node 可执行文件纳入发行包，包括相关许可证。

## 生命周期与会话

- `netease.py` 负责端口校验、独占占用检查、带随机令牌的健康检查、启动超时、崩溃重启和退出清理。
- `server.cjs` 仅监听 `127.0.0.1`，每次请求验证应用随机生成的 Bearer 令牌，仅开放下面的接口；不开放上游的完整 HTTP 服务。
- 应用首次登录或查询时按需启动服务。修改端口会停止旧服务，下一次请求在新端口启动；客户端保留当前登录会话。
- 服务每两秒检查父进程，应用意外终止时自行退出。正常退出会先终止服务，再等待后台任务结束。
- 上游缓存写到用户数据目录的 `netease/cache/`；安装目录保持只读。
- 登录 Cookie 自动存入项目根目录的 `.autoskyplay/credentials/`，使用未加密的本地 JSON，不再调用系统凭据库。凭据按用户数据目录隔离，端口变化不影响恢复。文件通过私有临时文件原子替换，POSIX 目录权限为 700、文件为 600，目录由 Git 忽略。项目内打包版同样定位项目根目录，独立发行包存放于应用旁的同名目录。运行时 Cookie 保存在共用客户端内存，以 POST body 传给内置服务，不进入 `state.json`、进程参数或环境变量，不记录请求内容；设置仅保存是否启用自动恢复的布尔值。原钥匙串不会读取或自动迁移，需要重新扫码一次。
- 主页和编辑页共用一个客户端与登录会话；主页登录后，编辑页显示相同账号并隐藏登录按钮。编辑页未登录时的入口也使用主页登录流程。
- 主页已登录的账号按钮单击只播放点击反馈，双击弹出退出警告，默认取消；确认退出后才清除会话及自动恢复设置。缪斯树屋账号使用相同交互。
- 启动时后台验证并恢复保存的 Cookie，主页与编辑页同步显示恢复进度及账号。网络、服务或本地凭据文件读取失败会保留保存的会话供重试；确认过期或凭据损坏时清除并关闭自动恢复。
- 扫码取消时忽略后续结果并撤回尚未提交的登录。退出登录即使上游失败也会清除本地会话和凭据文件；文件删除失败时仍关闭自动恢复，避免重启后再次登录。
- 本地凭据目录无法写入时保持本次登录可用，并在主页提示无法保存；启动冒烟测试不访问真实保存的会话。

## 接口适配

| 操作 | 内置路径 | 上游模块 | 使用的字段 |
| --- | --- | --- | --- |
| 登录二维码 Key | `/login/qr/key` | `login_qr_key` | `data.unikey` |
| 登录二维码图片 | `/login/qr/create` | `login_qr_create` | `data.qrimg`，PNG data URL |
| 登录轮询 | `/login/qr/check` | `login_qr_check` | `code` 800/801/802/803，成功后 `cookie` |
| 验证登录 | `/login/status` | `login_status` | `data.profile.userId/nickname` |
| 退出登录 | `/logout` | `logout` | 成功码 |
| 精确歌曲详情 | `/song/detail` | `song_detail` | `songs[].id/name/ar/al` |
| 歌曲音频 | `/song/url/v1` | `song_url_v1`（固定 eapi） | `data[].id/url/code/time/freeTrialInfo` |
| 分页单曲搜索 | `/cloudsearch` | `cloudsearch` | `result.songs/songCount` |

兼容歌曲信息中的 `ar/al` 和旧版 `artists/album` 字段。无效响应、错误码、
找不到歌曲、非歌曲链接、无法解析的短链接和封面错误都会给出中文提示。
精确查询会再次校验返回歌曲 ID；搜索以 10 条为一页，用户选择后按 ID 获取详情，避免同名版本误填。
专辑图片通过独立 HTTP 客户端下载，不附带登录 Cookie 或服务令牌，并限制为 8 MB。
封面地址仅接受网易云图片域名；短链接跳转仅允许网易云分享和歌曲域名。

升级时同时更新包版本和 npm 锁文件，检查以上响应字段及模块签名；
适配集中在 `netease.py` 和 `server.cjs`，编辑器无需依赖上游响应结构。
运行准备脚本后执行 `pytest`、`ruff`，验证真实歌曲详情、搜索、二维码生成和发行包启动。

## 验证边界

本次已通过服务进程启动/退出/崩溃重启、端口冲突、鉴权、接口错误、会话共用、
短链接、搜索版本选择、封面压缩保存和关闭窗口忽略回调等自动测试。
真实接口已验证歌曲详情、搜索结果、封面下载及二维码生成。
真实账号的手机扫码确认、Windows 安装和 Windows 运行时仍需在对应设备验收；
登录成功与取消、二维码状态和会话使用已有模拟测试覆盖。

在线扒谱使用播放地址及当前账号正常取得的音频；固定版本默认 xeapi 需要独立公钥，
内置路由为播放 v1 使用受支持的 eapi。歌曲不可用和仅试听状态独立处理，
不开放 unblock 或跨平台找源参数。音频通过无凭据客户端流式下载，大小限制 100 MB，
临时文件、取消与重定向规则见 [在线扒谱说明](TRANSCRIPTION.md)。
