# 在线扒谱：网易云音频，本地人声旋律识别

主页「在线扒谱」支持歌曲链接、分享短链接和歌曲 ID。复用现有网易云登录，
先读取歌曲信息和音频可用范围，再在本机处理。音频不上传到识别服务。
第一版面向人声主旋律；纯音乐、合唱和强和声需要人工校正，尚未提供器乐主旋律模型。

## 操作

1. 点击「选择歌曲」，搜索曲名/歌手，或使用链接/ID 定位；列表显示序号、封面、歌曲名、歌手、专辑和时长。
2. 选定歌曲后自动下载并生成真实波形，运行模型前即可试听原曲。仅能获取试听片段时，其余范围不可选。
3. 默认选中可用音频开头 30 秒。拖动入点/出点调整范围，拖动选区内部整体移动；也可输入精确秒数。
   波形支持缩放与全曲查看，滚轮平移、Ctrl+滚轮缩放；单击波形定位选段内的试听位置。
4. 点击「开始扒谱」。单次最多 10 分钟，下载上限 100 MB；下载好的音频会被识别任务复用。
5. 在三栏工作台查看历史草稿、只读曲谱预览与参数。窄窗口自动折叠草稿栏，可用「草稿栏」按钮重新展开。
6. 试听区切换原曲、分离人声、光遇曲谱，保留对应片段的播放位置；支持暂停、定位、循环和独立音色/音量。
7. 修改参数复用原始识别数据，无需重跑模型。显示网格默认 1/16，节拍吸附默认关闭。
   开启吸附后可选择 1/8、1/16、1/32，并手动调整网格起点。BPM 可自动估计或手动覆盖。
8. 「编辑曲谱」打开编辑器，「完成并返回草稿」回写人工修改，再由工作台「保存到曲库」。同名保存不覆盖已有曲谱。
9. 「导出原始 MIDI」输出经过当前过滤参数处理的原始旋律，不含光遇移调、吸附和人工修改。

顶部选段使用原歌曲时间；曲谱预览和试听进度从结果片段的 00:00 起算，并标注对应原曲起点。
修改选段不会改变旧结果；点击「重新识别」生成新草稿，取消或失败时已有结果仍会保留。
曲谱预览允许定位、缩放与滚动，不能添加、移动、删除音符；音符提示标明半音近似和音域折叠。
生成的是可编辑初稿，模型置信度不是准确率。BPM 估计失败时暂用 120；
自动 BPM 没有检测第一拍，所以节拍吸附必须由用户选择开启并检查结果。

### 草稿和缓存

- 识别完成、调参、编辑后自动保存到数据目录 `transcription/drafts/<id>/`。
- 草稿保存原始音高数据、参数、当前曲谱及来源信息；重启后点击左侧列表恢复。
- 对人工编辑版本再次调整生成参数，会创建新的草稿版本，保留原来的人工修改。
- 音频缓存按最近访问顺序清理，默认预算 1 GiB；正在使用的草稿暂不自动清理。
  原始识别数据、曲谱、人工编辑不受音频缓存清理影响。
- 「清理音频缓存」立即移除缓存音频；曲谱仍可试听、编辑和导出。
  原曲可点击「恢复音频」重新获取，受当前歌曲可用范围限制；分离人声需重新识别。
- 删除草稿不删除曲库中的歌曲。正常关闭自动保存；写入失败才提示用户决定是否关闭。

## 本地引擎组件

主程序不依赖或加载 PyTorch。扒谱引擎是独立 CPU 工作进程，组件包含 Python 运行时、
FFmpeg、Demucs 4.1.0 / HTDemucs、torchcrepe 0.0.24 / full、音频分析依赖及模型。
安装组件后识别过程离线运行，发行版用户无需另装 Python、FFmpeg 或模型。

在扒谱窗口导入对应平台的 `AutoSkyPlay-Transcription-1.0.0-<platform>.zip`。
安装会校验平台、版本、逐文件 SHA-256、路径与文件类型，完整校验后才切换当前组件。
构建同时产生 ZIP 的 SHA-256 文件。包内校验用于检查完整性，离线包应来自可信发行来源。
目前没有配置自动下载组件的发布地址，因此先提供离线导入。

组件保存在数据目录 `transcription/components/`；模型不会在任务结束时移除。
处理中间文件放在 `transcription/tasks/task-*`，波形准备临时目录为 `transcription/sources/source-*`；
成功后所需数据保存进草稿，临时目录在关闭窗口后清理。
取消下载会删除 `.part`；关闭正在处理的窗口会取消任务，工作线程结束后清理临时目录。
「设置 → 清理本地扒谱组件与模型」可移除安装的组件，处理或安装期间禁止清理。
该操作不会移除曲库中的谱面。源码运行的开发组件由构建脚本管理，不受该按钮影响。

## 开发与打包

```sh
uv run python scripts/prepare_transcription.py
uv run autoskyplay
```

也可运行 `uv run autoskyplay --transcribe` 直接打开扒谱窗口。

准备脚本创建独立 `.transcription-venv`，按 `engine/requirements.lock` 校验依赖哈希，
下载固定 Hugging Face 修订中的模型并按 `engine/models.json` 验证 SHA-256。
源码启动会发现该环境与 `build/transcription-models`。
主项目 Python 要求仍为 3.11+；引擎构建环境使用 Python 3.12。

```sh
uv run python scripts/prepare_transcription.py --package
```

此命令用独立环境冻结工作进程，复制模型与依赖许可证，进行启动检查，再生成离线 ZIP。
在目标系统上构建；Windows/macOS 手动 build workflow 会生成主程序和对应组件包。
Windows/Linux 使用 CPU 版 PyTorch；Intel macOS 单独锁定兼容的 PyTorch/NumPy 版本。
更新依赖或模型时先验证识别和冻结程序，再更新版本、锁文件、模型修订和哈希。

```sh
uv pip compile engine/requirements.in --universal --python-version 3.12 --generate-hashes \
  --index-strategy unsafe-best-match --output-file engine/requirements.lock
QT_QPA_PLATFORM=offscreen uv run pytest -q
uv run ruff check src tests scripts
```

已知音高的合成单声部检查可运行 `.transcription-venv/bin/python scripts/check_transcription_model.py`；
Windows 使用 `.transcription-venv\Scripts\python.exe`。该检查验证基础音高跟踪，
不代表混音歌曲或实际人声的整体识别准确率。

## 实现和验证边界

- 网易云播放 v1 固定使用上游支持的 eapi，避免默认 xeapi 的独立公钥要求。
  路由只接受歌曲 ID 和音质，不开放上游的 unblock、代理或任意 URL 参数。
- 音频 CDN 请求使用新的 HTTP 客户端，不附带登录 Cookie 或本地服务令牌；
  每次重定向均验证网易云音频域名，下载地址失效时刷新一次且重新校验试听范围。
- FFmpeg 裁剪为 44.1 kHz 双声道；Demucs 分离使用 30 秒外层块及上下文，
  模型内部采用 4 秒重叠块和可变长度推理，减少 CPU 内存占用。人声转为 16 kHz，
  torchcrepe 使用 32 帧批量，分块识别并丢弃重复上下文。
- 默认 CPU、最多 4 个计算线程、单个识别任务。工作进程有父进程退出监测；
  正常取消时结束进程树，避免 FFmpeg 残留。GPU 加速尚未实现。
- 固定 PyTorch 与 NumPy 随机种子，记录分块与批量参数，减少音高抖动采样带来的重复运行差异。
- 连续音高先经短窗平滑，再结合可靠程度、能量、起音与最短时长整理音符。
  移调、过滤和网格操作复用缓存，不重跑模型。
- 自动测试覆盖凭据隔离、试听范围、下载限制、取消与部分文件清理、原始时序、
  同音重复、静音、组件原子安装、工作进程失败及界面关闭/晚到回调。
- 本机已验证真实网易云试听下载和本地识别。Windows/Intel macOS 的冻结运行、
  真实账号的完整音频以及合唱、变调和复杂编曲的音乐质量仍需相应环境验收。
  不将单个片段的成功运行视为总体准确率评估。

引擎已完成冻结构建、窗口启动、ZIP 安装和逐文件校验。已验证真实网易云试听音频下载；

基础模型检查使用 6 个已知音高的合成单声部音符，检查其稳定区段的音高偏差；
结果均在半个半音以内。该检查不评估人声分离、起音准确率或真实歌曲的整体质量。
