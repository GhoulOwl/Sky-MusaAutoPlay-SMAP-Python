## 平台边界

Windows 是游戏演奏目标。源码启动时不自动提升权限；如果游戏是管理员进程，
AutoSkyPlay 也需使用相同权限。打包的 Windows 程序使用 UAC manifest 请求管理员权限。
macOS/Linux 支持界面、制谱、试听和本地练习。全局按键注入与游戏练习监听在这两个平台关闭。

启动默认试听。游戏演奏需要在播放器选择后手动启动，给用户留出切回游戏的倒计时。
与原版有所不同：程序不会在重启后自动恢复向游戏发送按键的模式。

数据存储在用户数据目录，不写安装目录。移除曲谱时移入 `trash/`，不会删除导入源文件。
凭据仅在用户勾选「记住登录」时存入操作系统凭据库；无凭据库的平台可使用会话登录。

## 原曲谱集合检查

共检查 1,591 个 JSON/TXT 文件，1,576 个成功；15 个未加载：

- 10 个加密曲谱，其 `songNotes` 为密文整数序列。没有原工具解密算法或密钥，不能按明文演奏。
- 5 个损坏或不属于支持格式的文本，包含空文件、非 JSON 文本、JSON 后附加文本、编码异常。

这些文件导入时会报告错误。其余文件保留绝对毫秒时间，不用取整 BPM 重算节奏。
第三方曲谱库未作为程序资源捆绑。

## Windows 游戏验收

在 Windows 上构建或启动后，验证：

1. 游戏拿出乐器，AutoSkyPlay 选择游戏演奏，倒计时后切到游戏。
2. 示例末尾四个和弦需同时触发；检查保持时长 25 ms 是否适合帧率，必要时调整。
3. F1 停止、F2 暂停、拖动进度、切歌和退出后，无琴键持续按住。
4. F3/F4 调速与 F5/F6 切歌在游戏前台生效。
5. 跟弹的游戏练习不吞掉游戏按键，程序自己的演奏注入不反过来推进练习。
6. 安装 / 升级保持用户曲库与收藏夹，下载更新后正常退出、安装并重启。
